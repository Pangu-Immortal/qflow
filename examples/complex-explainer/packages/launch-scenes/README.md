# Montage poster

This project package supplies the current `PosterTitle` treatment: a pink headline with a dark offset outline and a cream subtitle label. Text, subtitle, vertical position, sizes, gap and drawing order are useful author choices. The supplied Timeline Window determines its presence; the font is an explicit asset.

The Companion exposes those same fields through standard Studio controls and temporal lineage. Rendering owns local HTML/CSS and produces a visual contribution only. Earlier metal-title and introductory scene studies remain in private history; the active introductory and comparison scenes belong to `web-scenes`.
